# SabiRender 設計 v0

## 位置づけ

SabiRender は SabiDVI と SabiPDF が用いる **2D テクスチャのレンダラ**である。3DCG を想定したレンダラは Sabi 系列とは別に作る。
SabiRender を 3D 向けに一般化しない。

Sabi 系列の分担:

- SabiTeX: 組版（DVI を出す）。
- SabiFace: フォントを読む（メトリクス、符号化、字形の輪郭、フォントの解決）。
- **SabiRender**: PDF の図形モデルに従う描画。入口から受け取った描画命令列を画素にする。
- SabiDVI: DVI / XDV と dvipdfmx 方言の `pdf:` special を描画命令列に変換する入口。
- SabiPDF（将来）: PDF のページを描画命令列に変換する入口。

## 三層

| 層 | クレート | 内容 |
|---|---|---|
| 評価器 | `sabirender-content` | PDF 内容ストリームの字句解析と図形演算子の評価。図形状態（CTM、色、線の様式、クリップ、`q`/`Q`）を追跡し、描画命令列を出す |
| 描画命令列 | `sabirender-display` | 装置非依存の命令列。塗り・線・クリップ・字形・画像。入口と後端の唯一の接点 |
| 後端 | `sabirender-raster` | CPU 参照ラスタライザ。将来 GPU 後端を足すとき、この出力が基準になる |

評価器は入口が共有する。SabiDVI は `pdf:code` の中身を、SabiPDF はページの内容ストリームを、同じ評価器に渡す。

## 図形モデル

ISO 32000-1 §8 の図形モデルに揃える。3D 向けの概念（深度、投影、照明）は持たない。

- 経路は直線と三次ベジエ。塗りは非零規則と偶奇規則。
- 線は利用者空間で太らせる。非等方な CTM の下では線幅が向きにより変わるので、描画命令列は経路と CTM を分けて持つ。
- クリップは経路の内側に制限する命令（`ClipPush` / `ClipPop`）で表す。入れ子は交叉。
- 色は装置色空間（Gray / RGB / CMYK）をそのまま持ち、後端で変換する。透明度は定数アルファ（`gs` の `/CA` `/ca`）のみ。
- 字形は輪郭（経路）として入口が解決して渡す。後端はフォントを知らない。

未対応（`Unsupported` として記録し、検証時に数える）: テキスト演算子（TeX の文字は DVI 側で置かれるため PGF の出力には現れない）、
シェーディング（`sh`、PGF の `shade` 系）、パターン、インライン画像、ソフトマスク、ブレンドモード。

## 参照ラスタライザ

正しさの基準であって速さは目的でない。

- 折れ線化: 三次ベジエを平坦さの判定で二分。許容誤差は装置画素で 0.05。
- 塗り: 走査線法。縦は画素あたり 16 本の副走査線で標本化し、横は交点位置から被覆率を厳密に積む。縦方向の誤差は 1/16 画素以下。
- 線: 線分の矩形、接合の楔・扇形、端点の矩形・半円を独立の閉多角形にし、向きを揃えて非零規則で塗る。
  尖り接合は miter limit を超えると bevel に落とす（PDF §8.4.3.5）。破線は折れ線に沿って切る（§8.4.3.6）。線幅 0 は 1 画素。
- クリップ: 被覆率マスクの積。
- 合成: source-over、プリマルチプライしない f64 RGBA。

アンチエイリアスの方式は PDF 仕様が定めない。したがって他の処理系との比較は画素完全ではなく、許容誤差で行う。

## 検証の二層

1. **幾何の同一性**（入口の検証）: 同じ DVI を dvipdfmx で PDF にし、その PDF の内容ストリームを SabiRender の評価器で描画命令列に読み直して、
   SabiDVI が出した描画命令列と経路・CTM・色・線の様式を数値で比べる。ラスタライズを介さないので誤差の原因を切り分けられる。
   この読み直しは SabiPDF の入口そのものである。
2. **ラスタライザの妥当性**（後端の検証）: 解析的に面積が分かる図形（矩形、円、入れ子の正方形、線分、接合、端点、破線、クリップ）を描き、
   被覆率の総和を厳密解と比べる（`crates/sabirender-raster/tests/analytic.rs`）。GPU 後端は参照ラスタライザとの差分（`diff`）で検証する。

忠実度の基準は TikZ / PGF のマニュアル（`pgfmanual.pdf`）である。許容誤差は厳しく取る（幾何は 1e-6 bp、画素は 1 階調を超える画素の割合）。

## 座標

- 描画命令列の「ページ空間」は bp（1/72 in）、原点は左下、y 上向き（PDF の既定の利用者空間）。
- 後端は `page_to_device(page_height_bp, dpi)` でページ空間を画素座標（原点左上、y 下向き）へ写す。
- 入口が DVI の位置（sp、y 下向き）から `pdf:code` の基準行列を作る。1 bp = 65536 × 72.27 / 72 sp。
